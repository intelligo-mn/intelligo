# Support

- **Questions and ideas** — [GitHub Discussions](https://github.com/intelligo-dev/intelligo/discussions).
- **Bugs and feature requests** — [GitHub issues](https://github.com/intelligo-dev/intelligo/issues/new/choose), using the templates.
- **Security vulnerabilities** — privately, per [SECURITY.md](SECURITY.md). Never in a public issue.
- **Which versions get fixes, and how an API is retired** — [RELEASES.md](RELEASES.md).

Intelligo is maintained by a small team; there is no paid support
channel. The documentation is [intelligo.dev/docs](https://intelligo.dev/docs)
and the [README](README.md); to change something, start with
[CONTRIBUTING.md](CONTRIBUTING.md).
